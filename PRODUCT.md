# Product Context

## Product Purpose

An educational portfolio system demonstrating reproducible tabular machine learning, model comparison, explainability, API serving, and a usable interpretation dashboard.

## Users

- Recruiters and engineering reviewers evaluating data science and ML engineering depth.
- Data science learners exploring a complete local-first classification workflow.
- Developers testing prediction and explanation contracts through the API.

## Strategic Principles

- Say "model prediction" or "model output", never "diagnosis".
- Make the sample-based workflow primary; manual 30-feature entry is secondary.
- Keep generated evidence reproducible from scripts.
- Keep Python, API, and frontend workflows independently runnable.
- Treat Docker and MLflow as optional adapters.

## Register

product

## Anti-References

- Clinical decision-support software
- Patient management systems
- Decorative healthcare landing pages
- Notebook-only portfolio projects
