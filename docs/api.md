# FastAPI contract

Start the API only after generating and validating governed artifacts:

```bash
python -m src.pipeline --seed 42 --mlp-epochs 100
uvicorn src.api.main:app --port 8000
```

Endpoints:

- `GET /health`: process liveness;
- `GET /ready`: manifest and checksum readiness;
- `GET /model-info`: model version, positive class, threshold, calibration, dataset fingerprint, and limitation;
- `GET /features`: ordered 30-feature schema plus observed range references;
- `GET /samples`: 1 to 20 balanced educational dataset rows;
- `POST /predict`: one exact 30-feature object;
- `POST /predict-batch`: 1 to 100 exact requests.

Requests reject unknown or missing keys, numeric strings, booleans, non-finite values, and bodies over 256 KiB. Values outside observed ranges are accepted with warnings because observed ranges are not clinical validity bounds.

Responses use model-centered fields: classification, malignant-class score, threshold, calibration status, warning flags, artifact version, bounded contributions, and educational limitation. Scores are uncalibrated and are not clinical probabilities or individual risk.

The service validates repository-relative artifact inventory, feature order, label contract, dataset and split identity, model/evaluation selection, and SHA-256 checksums before `joblib.load`. Only trusted artifacts generated by this repository may be loaded.
