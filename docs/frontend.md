# React evidence dashboard

The React 19 and Vite 8 dashboard is an evidence reader first and a local dataset-row inference client second.

```bash
cd frontend
npm ci
npm run dev
```

Local mode connects to `VITE_API_URL` or `http://localhost:8000`. Production builds without `VITE_API_URL` use read-only showcase mode. The public Vercel site does not expose live inference.

The checked-in static values come from `frontend/src/data/showcase_contract.json`, generated by `python -m src.pipeline --publish-showcase`. Tests reconcile selected model, positive class, threshold, calibration, split counts, sample count, and confusion-matrix counts.

Pages:

- Overview: dataset, split, positive-class, calibration, selected-model, and error evidence;
- Prediction: governed dataset-row selection, optional 30-feature form, malignant-class score, threshold, OOD warnings, signed contributions, and visible limitation;
- Evaluation: validation-only candidate table and selected-model governed-test figures;
- Explainability: malignant-class SHAP orientation and validation-only threshold trade-off.

Keyboard focus, skip navigation, 44-pixel controls, `aria-live` results, text labels, semantic tables, reduced motion, loading, empty, error, warning, and mobile states are included. Color is not the sole source of meaning.

The local working tree may be ahead of the deployed showcase. Do not describe local changes as public until a separate deployment is approved and verified.
