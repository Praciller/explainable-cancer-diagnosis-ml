# Limitations

- The dataset is small and clean compared with real-world clinical data.
- It is a public educational dataset with no external validation in this project.
- Feature values are measurements from digitized images and are difficult for general users to enter.
- Metrics come from one deterministic split and have uncertainty not shown in the dashboard.
- Probabilities are not calibrated for clinical interpretation.
- Model explanations describe statistical behavior, not causality.
- Dataset shift, acquisition differences, demographic representativeness, and operational monitoring are not evaluated.
- The API has no authentication because it serves local public demo data only.
- The system is not suitable for medical diagnosis or clinical decision-making.
